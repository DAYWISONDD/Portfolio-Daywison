# Portfólio - Daywison Santos

Portfólio pessoal feito em HTML, CSS e JavaScript puro, sem framework nenhum.

Sou biomédico, trabalho há mais de 4 anos com sistemas de laboratório, suporte técnico e gestão de qualidade. Estou migrando pra desenvolvimento web e esse projeto é onde venho praticando o que aprendo, enquanto curso pós-graduação em Desenvolvimento Full Stack e Cloud Computing e em Desenvolvimento e Testes de Software. 

## O que tem no site

- Vídeo de entrada em tela cheia antes de carregar o conteúdo
- Cabeçalho com links pro LinkedIn, GitHub e contato
- Resumo profissional
- Formação acadêmica, com carrossel de imagens (graduação e pós, em andamento e concluídas)
- Experiência profissional, com foto que revela um texto por baixo ao clicar
- Certificações, com efeito de card que vira mostrando o diploma

## Tecnologias

- HTML5
- CSS3 (flexbox, grid, position, media queries pra responsivo)
- JavaScript (manipulação do DOM, classList, dataset)

## Sobre o projeto

É praticamente meu primeiro projeto de front-end. Fui construindo seção por seção, testando bastante, e cada parte do site (o carrossel, os cards que viram, o header, o responsivo) foi um problema resolvido na prática, um de cada vez. Ainda está em andamento e devo continuar mexendo com frequência.
